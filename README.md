# GoPro-Attachments-for-Trekking-Trip
This project is about an attachement for my backpack so i can mount my GoPro to the shoulder strap as well as a GoPro attachement to bind it to something (e.g. a tree). GoPro gear is expensive and from the few parts i have i want to reverse engineer the connection part for the mounting clip.

## Materials

Both are printed with PLA but other materials would probably be more suitable. Furthermore you will need a 3mm rope for the attachement with a rope.

## Printing

STL files are ready to slice, no CAD software needed. Or go to [Printables](https://www.printables.com/model/1803754-gopro-attachment-useful-for-a-trekking-trip), i have listed the files there as well.

## Backpack Attachement

Take the strap and slide it under the overhangs on the backside. It can be fiddly but it should work. After that you can mount the GoPro with the clip.

## Attachment with a Rope

Take the rope and put an ashley stopper knot on one end. To bind it to something try to do it the way it is shown in the picture below otherwise it tilts to one side. After that tighten it by using the clamcleat structure and you can mount the GoPro.

## Files

There are three folders each having an Creo, stl and stp folder. The Creo folder has the source files. There is also a folder that is called mountingclip, it only has the part that holds the clip from GoPro and needs a bottom plate to be useful. It has all the right dimensions and can be used for other attachements.

```
Folders:
backpackattachement           — attachment for mounting the GoPro to the backpack shoulder strap
attachmentrope                — attachment for binding the GoPro to something
mountingclip                  — a model of the part that the GoPro mounts to, it can be used for future models

Every folder has following files
Creo                          — contains all creo source files used for creating the step and stl files and has an assembly model
step                          — contains all step files
stl                           — contains all stl files

```
